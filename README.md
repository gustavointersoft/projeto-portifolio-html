#  Portfólio Acadêmico - Interface Homem-Máquina (IHM)

Este repositório contém o código-fonte do meu portfólio web pessoal e acadêmico, desenvolvido como atividade prática da disciplina de **Interface Homem-Máquina (IHM)** no curso de **Análise e Desenvolvimento de Sistemas (ADS)** do **IF Baiano - Campus Guanambi**.

---

##  Sobre o Projeto

O objetivo deste projeto é aplicar os conceitos de **desenvolvimento web semântico**, **design responsivo** e **acessibilidade (WCAG)**, utilizando apenas HTML5 e CSS3 nativos (sem a adição de bibliotecas externas ou scripts em JavaScript).

---

##  Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Estilização moderna utilizando:
  - **Flexbox** e **CSS Grid** para layout e alinhamentos.
  - **Variáveis CSS (`:root`)** para padronização de cores e tipografia.
  - **Media Queries** para responsividade completa (Mobile, Tablet e Desktop).
  - Validação nativa de formulários (`:user-invalid`, `:focus`).
- **GitHub Pages**: Hospedagem da aplicação em ambiente de produção.

##  Como Visualizar o Projeto

### Opcão 1: Acesso Online (GitHub Pages)
O projeto está publicado e acessível publicamente através do link:
(https://gustavointersoft.github.io/projeto-portifolio-html/)

### Opção 2: Execução Local
1. Clone este repositório para a sua máquina local:
   ```bash
   git clone https://github.com/gustavointersoft/projeto-portifolio-html.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd nome-do-repositorio
   ```
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
